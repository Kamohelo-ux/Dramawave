DRAMAWAVE STARTER — VERSION 1

WHAT'S INCLUDED
- index.html: the app interface and functionality
- manifest.webmanifest: installable web app settings
- sw.js: basic offline caching
- icon.svg: app icon

HOW TO TEST ON A COMPUTER
Open index.html in a browser. Some install/offline features require HTTPS or localhost.

HOW TO PUT IT ONLINE FOR FREE WITH GITHUB PAGES
1. Create/sign in to a GitHub account.
2. Create a NEW PUBLIC repository named dramawave.
3. Upload the four files in this folder (index.html, manifest.webmanifest, sw.js, icon.svg) to the repository root.
4. In the repository, open Settings > Pages.
5. Under Build and deployment, choose Deploy from a branch; select main and /(root), then Save.
6. Wait for GitHub Pages to publish. The site address will appear in Settings > Pages.
7. Open that HTTPS address in Chrome on Android. Use Chrome's menu > Install app or Add to Home screen (wording varies).

CONTENT NOTES
- The sample drama cards are demo catalogue entries, not actual licensed shows or playable episodes.
- Add drama saves titles and video links in browser local storage on this device only. They are not uploaded to a shared database and will not automatically appear on other phones.
- Video playback supports direct video URLs and YouTube/Vimeo embed URLs. For YouTube, use an embed URL such as https://www.youtube.com/embed/VIDEO_ID.
- Only publish videos you created or have permission to distribute. Respect the hosting provider's terms.
- This is a prototype, not yet a Play Store APK. No accounts, payments, subscriptions, ad network, analytics, or cloud content management are connected.
